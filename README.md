## Getting Started

Read my article about this project:
https://medium.com/@tiagolemesdaneluzzi/from-academic-knowledge-to-real-world-applications-integrating-firebase-auth-43fc8256e7dc

Install the dependencies:

```bash
npm i
```

Then, run the project:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
